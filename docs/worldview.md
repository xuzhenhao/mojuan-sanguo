# 《墨卷三国》世界观设定

> 文档状态：草案 v1（2026-10-13，总策划）。依据 PRD §1.3 名词表、§3 世界观与章节主题、§11 敌人设计，以及 `config/heroes/`、`config/enemies/`、`config/events/` 现有配置撰写。
> 本文只管「为什么」，不管「多少」：**所有数值、概率、次数一律以 config 为准**，本文不写。与 PRD 或 config 冲突时以 PRD / config 为准，并回头修本文。
> 游戏正式名称尚未确定，本文沿用暂定名《墨卷三国》。界面与文案字体统一用霞鹜文楷。

## 1. 世界观背景

三国的故事，本来好好地写在一部史书里：黄巾起、董卓乱、赤壁烧，人物各有其位，胜负各有其理。

不知从何时起，一种墨色的污迹渗进了卷页，它就是**墨魇**。墨魇不是哪一方的势力，而是「被写坏的历史」本身：它涂掉人名、颠倒胜负，把妖道写成天命所归，把乱臣写成万世之主。被它浸透的人物会变成「墨魇化」的样子，比如「张角·墨魇」，有原来人物的形貌和执念，却没有原来的分寸。被浸得浅一点的，便成了「墨影」，比如「华雄·墨影」「蔡瑁·墨影」。

史书一旦被污，就合不上。卷页每次打开，墨迹都要重新蔓延一遍，这也是故事能一次又一次重来的原因。

## 2. 「墨卷」核心设定

### 2.1 为什么是卷轴

- **历史是被写出来的。** 在这个世界里，历史的「真身」就是书写本身。谁执笔、怎样落墨，决定了卷中发生什么。所以战斗不是改变过去，而是**改写一段被污的文字**。
- **卷轴是能反复展开的。** 一卷画轴可以展开、合上、再展开。失败了，卷页合上；再入卷，墨迹重新铺开，但路线未必一样。这正好对应 Roguelike 的「每局重来、每局不同」，同时也解释了地图为什么整张展开、一览无余（PRD §10.2「不做迷雾」）：卷轴摊开在你面前，路是看得见的，只是每一段写着什么，要走进去才知道。
- **水墨就是这个世界的物质。** 人物是墨写的，敌人是污墨聚成的，玩家手里的力量也是墨。视觉上的水墨卷轴风不只是包装，而是世界的规则：墨浓则强，墨散则亡；通关时卷轴合上（PRD §3.3），象征这一段文字已被写定。

### 2.2 玩家身份：执笔者

玩家是**执笔者**（PRD §1.3）：一位能持笔入卷的书写者。执笔者自己不上阵厮杀，他做两件事：

1. **请将入卷。** 执笔者以武将之魂为墨（PRD §3.1），把一位武将「写」上前台当主将，再请一位在侧当副将。
2. **落笔应对。** 每一张出牌，就是执笔者在卷上落下的一笔：杀是锋芒，闪是避让，锦囊是计谋，判定是向天问签。

执笔者没有名字、没有固定样貌，这是有意留白：玩家就是那支笔。

### 2.3 墨魇为什么一再卷土重来

墨魇被打退一分，卷页就干净一分；但污迹没有根除之前，史书总会再被翻开。执笔者每在更深的墨色里通关一次，就能面对更浓的墨魇，这就是**天命**：卷中墨魇越浓，所需的笔力越重。

## 3. 章节叙事主线

MVP 共三章（PRD §3.2）。每章是一卷，章首一屏水墨插画加 2–3 句旁白，Boss 前有短对话，通关时卷轴合上（PRD §3.3）。剧情不挡玩法，可跳过。

### 3.1 第一章 · 黄巾乱世（已定）

**卷首**：中平元年前后，天下大旱，流民遍野。墨魇最先渗入的就是这一卷：它找到了一个本就喊着「天命」的人——张角。

**卷中**：执笔者一路穿过被黄巾旗帜染黄的乡野。所遇敌人都来自第 1 章配置：

- 黄巾步卒、流民暴徒：被墨迹裹挟的寻常百姓，冲在最前；
- 黄巾弓手、黄巾咒师：站在后排，弓手放箭，咒师念咒乱人手中之牌；
- 精英「张宝」：张角之弟，借黄天庇佑结阵自保；
- 「波才残部」在 config 中暂不启用，叙事上留作伏笔。

沿途奇遇（以 `config/events/ch1/` 为准）如路边桃园、华佗诊所、古井、驿站、叛军劝降等，都是这一卷里「还没被墨完全涂掉的角落」，执笔者在其中补给、抉择。

**卷末 Boss：张角·墨魇。** 历史上张角号称「大贤良师」，以太平道聚众。墨魇放大了他「苍天当死」的执念，让他相信自己真能召来天雷。

- 登场台词（以 `config/enemies/ch1/B1-zhangjiao.yaml` 的 `intro.line` 为准）：「苍天已死，黄天当立！」
- 二阶段台词（`intro.phaseLine`）：「天雷在此——黄巾儿郎，随我死战！」

战斗中，他把「闪电」落到执笔者身上，借天机签筒问雷；二阶段召来黄巾弓手死战（机制与数值以 config 为准）。击败他后，被涂黄的卷页褪回原色，卷轴合上。通关可得「太平要术残页」一类的宝物（PRD §11.2），寓意墨魇从张角那里留下的残迹。

### 3.2 第二章 · 讨董烽烟（方向，待定）

- 主题：西凉铁骑、洛阳残火（PRD §3.2）。
- Boss 方向：董卓（墨魇化）。墨魇放大的是「据天子以令群雄」的贪欲，焚城即焚卷。
- 精英方向：华雄·墨影、李傕郭汜。
- **待定**：章首旁白、Boss 台词、Boss 配置（目前 `config/enemies/ch2/` 尚无 Boss 文件）。

### 3.3 第三章 · 赤壁江雾（方向，待定）

- 主题：水战、火攻、东风（PRD §3.2）。
- Boss 方向：曹操（墨魇·水火双形态）。注意曹操同时是可选武将，叙事上的处理是：**Boss 是墨魇借曹操之形写出的「伪笔」**，执笔者请来的曹操是「真迹」。真迹与伪笔可以同场，这本身就是本章的看点。
- 精英方向：蔡瑁·墨影、苦肉周瑜影（同理，是周瑜的伪笔）。
- **待定**：章首旁白、Boss 台词、真迹与伪笔同场时的专属对话、Boss 配置。

## 4. 武将入卷的理由

武将是执笔者「以魂为墨」请入卷中的人物。每一位都和墨魇有一笔账：墨魇污的是他们的历史，他们入卷是为了把自己那一页写回来。技能名与专属事件名均取自 `config/heroes/`，具体效果以 config 为准。

| 编号 | 武将 | 势力 | 入卷的理由 |
| ---- | ---- | ---- | ---------- |
| H01 | 吕布 | 群 | 史书写他「三姓家奴」，也写他「人中吕布」。墨魇只留下了前一半。他入卷，要用无俦的戟把后一半写回来。「凤仪亭」「辕门」是他最不想被涂改的两页。 |
| H02 | 貂蝉 | 群 | 她在正史里几乎没有名字，本就是半写半留白的人，所以最懂得怎样在字缝里行事。离间、连环计，是她以笔为刃的方式。「铜雀」一页寄托着她被后人续写的命运。 |
| H03 | 赵云 | 蜀 | 一身是胆，长坂救主。墨魇最想抹去的就是「忠」字。他入卷护主，龙胆让杀闪互转，是攻守都不离其位。 |
| H04 | 刘备 | 蜀 | 仁义之名是他在乱世里的全部本钱。墨魇把仁义写成伪善，他入卷要证明仁义能续命。「长坂护主」「煮酒论英雄」与赵云、曹操都有牵连。 |
| H05 | 郭嘉 | 魏 | 天妒英才，早逝的谋士。他的那一页本就短，他比谁都想多写几行。越受伤越看得清局面（天策、遗计），正是一个「来不及写完」的人的执念。 |
| H06 | 曹操 | 魏 | 宁我负人的奸雄。墨魇在第三章借他之形作伪笔，真迹的曹操入卷，要亲手斩掉「被写坏的自己」。「奉孝遗策」「青梅」两页连着郭嘉与刘备。 |
| H07 | 周瑜 | 吴 | 赤壁之火本是他的，却被后世写成别人的功劳。他入卷，要把火重新点在自己的笔下。「赤壁双璧」连着第三章。 |
| H08 | 陆逊 | 吴 | 书生拜将，以火烧连营成名。他谦逊、不受咒扰，是最像执笔者的武将：手中墨尽，便又续上（连营）。 |

**关羽（H09）**：config 中保留了配置文件，但目前不进开局名单、不出现在点将页（PRD §7.2）。叙事上暂写为「名已在卷，尚未入卷」，开放时间与入卷故事**待定**。

## 6. 「墨卷」意象的去留与影响清单

用户已说明「墨卷」只是暂用名，世界观可以跳出卷轴设定，水墨美术风格不变。

### 6.1 本稿的取舍

本稿**保留卷轴作为默认方案**，原因：PRD 名词表里的执笔者、墨魇、墨影，地图的整卷可见、通关卷轴合上，都已经和卷轴自洽；换掉它要同时改叙事、地图表现和多处文案。

但核心意象其实是「**写坏的史书 + 执笔改写**」，卷轴只是史书的载体。若正式名称不带「卷」，可改用下面的备选，墨魇、墨影、执笔者都能原样保留：

| 备选意象 | 说法 | 需要调整的地方 |
| -------- | ---- | -------------- |
| 青史 / 史笔（推荐的替代） | 被墨魇污染的是「青史」，玩家是执「史笔」的人；一章是一「篇」，通关是「定稿」，失败是「废稿重写」 | 「入卷」「卷轴合上」类文案改成「入史」「落定」；地图仍可画成长卷，美术不受影响 |
| 画境 | 史事凝成一幅幅水墨画，玩家入画 | 与已有作品《蚀魂图：墨魇》（入古画、墨魇）意象过近，**不推荐** |

## 8. 核心动机：修正世界线（补充设定）

> 本节把「主副将合体」「跨阵营联手」「魔化从哪来」串成一条线，主动机统一为**修正世界线**。卷轴只是这条线的画面载体，换意象时本节仍然成立（见 §6）。

### 8.1 魔化从哪里来

- 三国本来只有一条**正史世界线**。墨魇是从这条线的裂口里渗出来的：历史上那些「差一点就改写天下」的执念，如果没有被正史收住，就会凝成墨魇。
- **张角是第一个裂口。** 他是中平元年那场「苍天已死，黄天当立」的发起者，执念最重、时间最早。墨魇借他的执念把他魔化成「张角·墨魇」，让他真的召来天雷（闪电判定），黄巾也就从起义变成一场要吞掉整条世界线的劫数。
- 墨魇不偏任何阵营。它要的不是哪一家得天下，而是**世界线断掉**：如果黄巾吞了汉末，就不会有讨董，不会有赤壁，也就没有魏、蜀、吴。

### 8.2 各阵营为什么放下立场联手

- **因为墨魇吞的是所有人的未来。** 张角若赢，曹操成不了奸雄，刘备立不了蜀汉，周瑜点不了赤壁的火，吕布也不会有辕门射戟。对每位武将来说，正史再不如意，也是自己存在过的唯一证明。
- **所以他们争的是「在正史里怎么斗」，不是「要不要有正史」。** 先把世界线修好，各自的恩怨留给正史去算。曹操与刘备「煮酒论英雄」时互为对手，在这里却同样需要那场煮酒真的发生过；吕布与赵云从未同阵，但他们都要靠这条线才能留下名字。
- **执笔者是唯一站在线外的人**，所以由他来请将、配将，阵营不设限（PRD §7.1：主副可任意组合，只是不可同一人）。

### 8.3 主将与副将为什么能合体

先对照实际机制（PRD §7.1、§7.4，`config/heroes/` 的 `mainSkills` / `subSkill`、珠联配置）：

| 机制 | 规则（以 PRD / config 为准） | 设定解释 |
| ---- | ---------------------------- | -------- |
| 1 主将 + 1 副将，不可同一人，阵营不限 | 开局点将 | 世界线裂口太窄，一次只能容一位武将「实身」入线，另一位只能以「魂」相随 |
| 主将有体力、装备区、主将技 | 主将上场 | 实身入线的武将，会受伤、能披挂 |
| 副将无体力、无装备、不会阵亡，只提供副将技和专属牌入奖励池 | 副将不上场 | 相随之魂不在线内，打不着也死不了，只能把自己的一招（副将技）和惯用之物（专属牌）借给主将 |
| 主将阵亡即失败 | 战败 | 实身倒下，这一段世界线就再次断开，执笔者只能从头修 |
| 珠联璧合：特定主副组合额外加成（如刘备+赵云「长坂护主」、曹操+郭嘉「奉孝遗策」、吕布+貂蝉「凤仪亭」） | 组合加成 | 两人在正史上本就同在一段线上，魂与身同频，借力更顺 |
| 跨阵营组合也能成立，只是没有珠联 | 任意组合 | 没有旧缘，但同为修线而来，照样能借力，只是少了默契 |

所以「合体」不是两人变成一人，而是**一身一魂**：主将以身入线，副将以魂附身。

### 8.4 和「修正世界线」的整体对照

| 玩法 | 修正世界线的说法 |
| ---- | ---------------- |
| 一局 | 修补一段断开的世界线 |
| 地图节点 | 世界线上一个个将断未断的节点 |
| 击败 Boss | 收住一个裂口，这一段世界线回归正史 |
| 败北重来 | 这一段又断开了，再修一次，每次路线不同 |
| 天命 | 裂口越深，墨魇越浓 |
| 兵书 | 执笔者把修线时写出的好笔留在线外，下次带回来 |

### 8.5 后续章节 Boss 怎么延续（方向，待定）

每章 Boss 都是「一位差点改写天下的人，被墨魇放大了执念」：

- **第二章 · 董卓·墨魇（待定）**：执念是「据天子以令天下」。墨魇让他把洛阳连同世界线一起烧掉（焚城）。各路诸侯在正史里本就短暂会盟讨董，这一章的联手最顺理成章。
- **第三章 · 曹操·墨魇（待定）**：最难的一章。墨魇放大的是曹操「宁我负天下人」的那一面，借他的形写出伪笔。玩家可以用真迹曹操去打伪笔曹操：真迹选择守住赤壁之败，因为只有败过的曹操才是正史的曹操。
- **之后（待定）**：墨魇为什么从张角开始、裂口最终在哪里，留作长线悬念，等内容规划确定再写。

## 9. 「为何而战」变体（供用户选，选定后合并进 §1–§3）

| 变体 | 一句话 | 主动机 | 优点 | 缺点 |
