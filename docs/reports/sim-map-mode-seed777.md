## 验收（spec §8）
1. 同 seed 两次一致：✅（tests/sim-map-mode.test.ts）
2. 节点次数 ±30%：普通战 3.9–4.5（+8~+24%）、奇遇/商店/营地 ✅；**精英 0.29–0.39 ⚠（期望 0.70，−45~−59%）**，宝箱部分 −30% 边缘。原因：§3 规定精英仅在体力 ≥70% 时主动选，且优先级低于战斗/奇遇/宝箱/商店；需数值确认是改路线规则还是改期望口径。
3. k=0 低于三战制回 0 基线 67.6%：不含复活 8 将均值 **62.0%** ✅；含复活 77.4%（复活抬高约 15pp）。同种子本实现的三战制回 0 基线 8 将均值 68.8%。
