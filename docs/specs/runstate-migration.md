# 旧存档迁移规格（RunState v1 · 对应 #122 第 5 点）

来源：PRD §21.4（断点续玩存档、`battleStartSnapshot`、版本不一致回滚）、#122 统一局状态方案（PR1–PR3）。
本文是给开发的落地口径：旧版 `RunSave` 读入新版 `RunState` 时，如何处理**存档时正处在战斗中**的情况。

---

## 1. 总则
| 项 | 规则 |
|---|---|
| 战斗中状态 | 迁移时**全部丢弃**（牌堆顺序、手牌、敌人意图、Buff 等 `battleState`），不尝试转换 |
| 回退点 | 回到**该战斗节点开打前**；节点保持**未完成**，玩家重打本场 |
| 不做的事 | **不判负、不跳过**该节点，不发放战斗奖励 |
| 不在战斗中的存档 | 直接按字段映射迁移，不回退、不提示 |

## 2. 回退范围
以下字段全部取**进入该节点那一刻**的值，避免白丢或重复使用：

| 字段 | 说明 |
|---|---|
| 体力 | 当前体力与最大体力 |
| 牌组 | 含词条、实例 id |
| 复活次数 | `reviveLeft`；战斗中已用掉的复活要还回来 |
| 丹药 | 战斗中喝掉的丹药要还回来 |
| 一次性宝物 | 如 R15 七星灯（每局 1 次免死）；战斗中已触发的恢复为未触发 |

- **数据来源**：`battleStartSnapshot`（进入战斗时写入，PRD §21.4）。
- **快照字段不全**：旧快照缺少上表某几项时按同一规则处理——缺的项由**上一个已完成节点**的状态推出（进节点前没有其他结算会改动这些值），不取战斗中的当前值。
- 铜钱、地图路线、其余宝物等快照里有的字段一并按快照恢复。

## 3. 无快照的旧档
- `battleStartSnapshot` 为空或不存在 → 退回**上一个已完成节点**的完整状态（地图停在该节点之后、下一步可选节点重新可选）。
- 同样不判负、不跳过。

## 4. 提示
| 情况 | 文案 |
|---|---|
| 有快照 | 「存档已更新，本场战斗重新开始」 |
| 无快照 | 「存档已更新，已回到上一处」 |

- 形式：顶部 toast，墨底白字，显示 **2.5s**，**不弹确认框**（与 §21.4 配置版本回滚的确认弹窗区分）。
- **与配置版本回滚同时触发**：当同一存档同时触发配置版本不一致（PRD §21.4）和旧档迁移时，只弹 §21.4 的「继续」确认框，不再叠加 toast；回退点取两者中更早的那个。
- 分工：**PR1** 在迁移结果里留钩子（如 `migration: { kind: 'battle_rollback' | 'node_rollback' }`），只返回需要提示的类型；**PR3** 接 UI 做 toast 样式。

## 5. 战斗中途刷新（#122 组长第 3 条）
- **战斗中途不存档**，只在进入战斗节点时存进节点快照（`battleStartSnapshot`）。
- 战斗中途刷新 / 退出后重进 → 回到**该战斗开打前**重打；节点保持未完成，不判负、不跳过。回退范围同 §2（体力、牌组、复活次数、丹药、一次性宝物都取进节点那一刻的值）。
- **battle 随机流**（`rngState` 中的 combat 流）也恢复到进节点那一刻：重打时的发牌顺序和敌人意图与第一次**完全一致**，防止靠刷新重抽。
- 提示走 §4 同一通用钩子（如 `kind: 'battle_refresh'`），顶部 toast，样式同 §4，文案「已回到本场战斗开打前」。

## 6. 其他
- 淬炼改走 event 流后，营地淬炼消耗随机数的顺序变化，旧档读入后的随机序列与旧版不一致。**可接受**：H5 没有对外存档、没有云同步，不影响防 SL（迁移后的新档继续保存 `rngState`，读档可复现）。
- 迁移只发生一次：写回新版本号后不再重复迁移。

## 7. 验收清单（单测口径）
- [ ] 战斗中旧档 + 完整快照 → 回到节点开打前，节点未完成，`battleState` 为空，提示类型 = 有快照
- [ ] 回退后体力、牌组、`reviveLeft`、丹药、七星灯等一次性宝物均等于快照值（战斗中用掉的全部还回）
- [ ] 快照缺复活次数 / 丹药 / 一次性宝物任一项 → 该项取上一已完成节点状态，不取战斗中当前值
- [ ] 无快照旧档 → 回到上一已完成节点完整状态，提示类型 = 无快照
- [ ] 任一情况都不判负、不跳过、不发战斗奖励
- [ ] 非战斗中旧档 → 字段映射迁移，无回退、无提示
- [ ] 迁移后再序列化 / 反序列化一次，结果一致；再次读档不重复迁移
- [ ] 同时触发配置版本不一致与旧档迁移 → 只弹 §21.4「继续」确认框、无 toast，回退点取两者中更早的那个
- [ ] 战斗中途刷新 → 回到开打前，回退范围同 §2；重打前 3 回合的手牌和敌人意图与第一次一致
- [ ] 战斗中途刷新 → 提示类型 = 中途刷新，toast 文案「已回到本场战斗开打前」
- [ ] 迁移后读档随机结果可复现（同一存档读两次结果一致）
