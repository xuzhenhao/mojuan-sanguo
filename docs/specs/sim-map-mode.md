# 自动试玩 · 整章地图模式口径（sim-map-mode v0.1）

用途：复测 O35，并给出第 1 章完整地图通关率（PRD §14.4 目标 65–80%，8 将各自落在均值 ±10% 以内），作为郭嘉线调优的依据。
负责人：口径由数值策划给出，实现由测试负责（autoplay）。

## 1. 原则
- **不另写地图逻辑**：地图用 `generateMap(runSeed, chapter, CONFIG.rules.map)` 生成；战斗用 `drawEncounter` 从 `encounters/ch1.yaml` 的 `pools` 抽取；营地回复用 `applyRestHeal`（`src/core/run/rest.ts`）。
- 回复口径用 `rules.map.betweenBattleHeal`（当前是 0），**不读** `sim.baselineBetweenBattleHeal`。三战制回归保持原样，两种模式并存。
- 可复现：同一个 `--seed` 得到同一张地图、同一组战斗和同一条路线。随机流按 `hashSeed(seed, 'sim-path' | 'sim-event' | 'sim-reward', …)` 分开。

## 2. 入口
`npm run autoplay -- --mode map [--hero H05 --sub H06] [--n 200] [--seed 777] [--all-heroes]`
- `--all-heroes`：8 个主将依次跑，副将用 PRD §14.4 v2 复测里的固定搭配（H01+H02、H02+H01、H03+H04、H04+H03、H05+H06、H06+H05、H07+H08、H08+H07）。

## 3. 路线选择（sim AI）
每层从 `availableNodes` 里按下面的顺序选：
1. 体力 ≤ 40% 时：REST > EVENT > SHOP > CHEST > BATTLE > ELITE。
2. 其他情况：BATTLE ≈ EVENT > CHEST > SHOP > ELITE > REST。同一优先级的节点等概率随机。
3. 精英：只在体力 ≥ 70% 时主动选。
- 报告里输出实际走到的各类节点平均次数，和 PRD §10.4 的期望（普通战 3.6、精英 0.70、奇遇 1.2、商店 0.76、宝箱 0.48、营地 0.28 + 第 8 层 1）对照。偏差超过 ±30% 时在报告里标出来。

## 4. 各节点结算
| 节点 | 结算 |
|---|---|
| BATTLE / ELITE / BOSS | 用 `drawEncounter` 抽组包，跑真实战斗；体力继承。普通战前 2 场用 easy 池（`rules.easyBattles`） |
| REST | **固定选疗伤**：`applyRestHeal(hp, maxHp, rules.map.rest)`。体力已满时改为淬炼，按第 5 节折算 |
| EVENT | 按第 6 节的期望值折算，不跑事件界面 |
| SHOP | 按第 5 节折算 |
| CHEST | 按第 5 节折算 |
- 战斗失败：H5 每局免费复活 1 次（O25）。复活后按 PRD §4.4 的回复量继续，报告里另外输出「不含复活的通关率」。

## 5. 奖励折算（v0.1，按期望值，不跑选牌）
卡牌奖励先不真实入组，统一折算成**每场战斗开场护甲 +k**，用一个可调参数体现「牌组变强」：
- 每场普通战胜利 +0.15，精英胜利 +0.3，商店购买 1 张 +0.2，淬炼 1 次 +0.15，宝箱宝物 +0.2；开场护甲上限 4（第 4 层起生效）。
- 这些系数是**占位值**，第一轮先跑 k=0（完全不计奖励）和上面这组系数两版，给出通关率区间。v0.2 再换成真实入组：三选一取价值模型（§14.7）最高的那张。
- 铜钱照常记账（§14.1 收入、§14.2 价格），用于校验收支表：报告里输出到 Boss 前持有铜钱的中位数，以及花在买卡、删牌、事件上的次数。

## 6. 奇遇折算（8 个事件等概率无放回抽取；池抽空时降级成 easy 战斗）
| 事件 | sim 选择 |
|---|---|
| V01 | 体力没满选回 2，满血选桃入组（记 +0.1 护甲） |
| V04 | 铜钱 ≥ 90 时押注（真随机 50%），否则不赌 |
| V05 | 铜钱 ≥ 75 买 E 牌（+0.3），否则离开 |
| V06 | 投签：用签筒判定，红色回 2，黑色失 1（最低剩 1）并得 R 牌（+0.15） |
| V09 | 体力 ≤ 50% 选刮骨（上限 −1、回满）；否则铜钱 ≥ 40 抓药，再否则离开 |
| V13 | 体力 ≥ 60% 剿灭（easy 池独立抽，铜钱 ×2），否则收编（下一场开场 +3 甲） |
| V14 | 貂蝉在队得专属牌（+0.2），否则 +40 铜钱 |
| V19 | 铜钱 ≥ 60 且缺血 ≥ 3 时包上房，否则歇一晚回 2 |

## 7. 报告输出
- 每将：通关率（含复活、不含复活）、Boss 入场体力中位数、各类节点次数、到 Boss 前铜钱中位数、死在第几层的分布。
- 8 将均值，以及每将相对均值的偏差；超出 ±10% 的加粗。
- 两版奖励系数（k=0 和第 5 节系数）各出一张表。

## 8. 验收（数值策划）
- 同一个 seed 跑两次结果完全一致。
- 节点次数对照第 3 节，偏差在 ±30% 以内。
- k=0 那一版的通关率应该**低于**三战制回 0 的基线（67.6%，种子 777），否则就是营地或事件折算算多了。
