## 1. 灵光一闪（P2 子层，`v3/epiphany.html`）

### 1.1 触发
| 项 | 规则 |
|---|---|
| 监听 | 玩家打出且**成功结算**的牌；被无懈的锦囊、被闪的杀不触发 |
| 装备 / 闪 | 装备进入装备区时判定；闪成功抵消杀时判定 |
| 概率 | 基础 8%（第 2 章 +2%，第 3 章 +3%）+ 宝物修正 |
| 每场上限 | 2 次（宝物「墨魇碎片」+1） |
| 软保底 | 本场累计 12 张未触发 → 下一次必触发（仍受上限） |
| 随机源 | 局内 rng，可复现；存档带 `epiphanyCount`、`pityCounter` |

### 1.2 候选生成
- 按牌 `category` 取词条池（全稀有度 N/R/E/L，权重见 §8.5 / 配置）。
- 过滤：同名词条已在该牌上 → 排除；`mutex` 冲突 → 排除；锋锐 `maxPerDeck: 2` 已满 → 排除。
- 取 3 条不重复；不足 3 条按实际数量展示；**0 条则本次不弹层、不计次数、不重置保底**。

### 1.3 操作
| 情况 | 可选操作 |
|---|---|
| 该牌词条 < 2 | 三选一，**必须选一条**（无取消） |
| 该牌词条 = 2 | 三选一后，再选**替换**已有哪一条；或点「放弃」（不计入保底重置以外的任何收益，次数照常消耗） |
| 刷新 | **H5 不提供**（无广告）；微信版每次灵光 1 次广告刷新 |

### 1.4 状态与出口
- 弹层期间战斗暂停，响应倒计时冻结，倍速不影响，不可跳过。
- 选定 → 写入该牌**实例**的 `modifiers[]`（局内牌组永久）→ 关闭 → 继续结算剩余流程。
- 存档：灵光弹层是一个决策点；弹层打开时杀进程，重进恢复到**同一组候选**，不重抽。
- 埋点：`epiphany_show`（cardId, 候选 ids, 是否保底）、`epiphany_pick`（affixId, replace?）。

## 2. 复活（P2 子层，`v3/revive.html`）

### 2.1 触发
- 主将体力降至 0，濒死流程（桃、酒、宝物「平安符」等）全部未救回后判定。
- 弹出条件：`reviveLeft > 0` 且 天命 < 5。否则直接进 P5 败北。
- H5：每局免费 1 次（O25 已结案）。

### 2.2 效果
- 体力 → `max(2, ceil(maxHp × 25%))`（7/8 → 2，9 → 3）。
- 获得 3 护甲（受护甲保留规则约束）。
- 敌方意图改闪：
  1. 若复活发生在敌方回合中，本回合**未结算的出牌全部取消**。
  2. 下一个敌方回合，所有存活敌人意图替换为 `[闪]`（每人 +1 闪标记，上限 2）。
  3. 该回合后各敌人从**被替换前的那一步**继续循环，被替换的步不补打。
  4. 意图栏复活后立即显示新的闪意图。

### 2.3 操作与出口
| 按钮 | 结果 |
|---|---|
| 复活 | 执行 §2.2 → `reviveLeft = 0` → 回战斗（若在玩家回合则继续本回合，若在敌方回合按 2.2-1 处理） |
| 放弃 | 本局失败 → P5 败北（将魂 ×0.5） |
- 不可点遮罩关闭；无倒计时（H5）。
- 存档：复活弹层是决策点；杀进程重进回到复活弹层。
- 埋点：`revive_show`、`revive_choose`（revive / giveup）。

## 3. 首领确认（P3 子层，`v3/boss.html`）

### 3.1 触发
- 地图上点选 **BOSS** 节点时弹出。精英节点不弹（只播 0.8s 名牌）。

### 3.2 内容
- 标题：「进入首领战？（之后无法返回）」
- 显示：Boss 名称与头像、当前体力 / 上限、护甲（如有）、丹药 3 格、铜钱。

### 3.3 操作与出口
| 按钮 | 结果 |
|---|---|
| 整备 | 关闭弹层，留在地图（可丢弃丹药、看牌组）；节点保持可选 |
| 出战 | **先写存档**（当前节点 = Boss，状态 BATTLE），再进 P2 → 播登场演出 |
- 登场演出约 2s（名牌 + 一句台词），点击可跳过；同一 Boss 第二次起默认 0.8s。张角阶段 2 切换播约 1s。
- 埋点：`boss_confirm_show`、`boss_confirm_choose`（prepare / fight）。

## 4. 放弃本局（`v3/abandon.html`）

### 4.1 入口
1. 启动时有存档：P1 上弹「继续本局 / 放弃本局」（`v3/resume.html`）。
2. 设置浮层（P2 / P3 暂停中）里的「放弃本局」。

### 4.2 二次确认（文案一字不差）
> 放弃后本局按失败结算，将魂减半，存档将被删除。确定放弃？

- 按钮：「返回」（左）/「确定放弃」（右，朱砂色）。
- 「返回」：入口 1 回到继续/放弃弹层；入口 2 回到设置浮层。

### 4.3 确定放弃后
- 按**失败**进 P5：将魂按 §14.5 用实际进度计算后 ×0.5（向下取整），天命加成照常。
- 统计中记录 `abandoned: true`（结算页显示「败北」，不另起样式）。
- 结算完成后删除 `RunSave`，写入局外存档。
- 战斗中放弃：当前战斗不计胜场；灵光已获得的词条照常计入兵书可抄（与失败一致）。
- 埋点：`run_abandon`（入口 1/2，层数）。

## 5. 裁定（对齐冲突，已回写 PRD）
1. **灵光一闪满 2 条词条时可放弃**：flow.md「不能取消」只适用于词条 < 2 的情况；满 2 条时按 PRD §8.6 可替换或放弃。
2. **H5 灵光一闪不提供刷新**：H5 无广告，PRD §8.4-4 的广告刷新只在微信版。
3. **复活 H5 免费 1 次已结案**（O25）：flow.md §3.6「【待用户决策】」标记作废。
4. **候选 0 条不弹层、不计次数**：PRD 原文未覆盖，按此执行。
