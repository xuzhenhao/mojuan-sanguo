## 0.2.0 — 2026-10-12

### 设计决策：取消攻击力数值，伤害全部来自卡牌

- **没有独立的攻击力系统。** 所有伤害都由打出的牌本身决定。
- 敌人的【杀】与玩家相同，**只造成 1 点伤害**；除非该牌经「灵光一闪」进化出改变伤害的词条（如「锋锐」+1）。
- 敌人意图不再显示数值（如 ATK:5），而是显示将要打出的牌：`杀×2`、`备闪`、`万箭齐发`、`杀[锋锐]`。
- PRD 第 11 章的 ATK/DEF/DEBUFF 循环映射为出牌：ATK→杀（重击→多张杀 / 万箭），DEF→备闪（闪标记，上限 2），DEBUFF→咒（随机弃 1 张手牌）。
- 敌人护甲只来自技能：张宝·墨影「黄天庇佑」——有后排友军时每回合护甲 +1。
- 精英张宝携带已进化的杀「锋锐」（2 点），在意图上显示词条。
- 移除原型中的「敌人意图 ÷3」临时平衡开关。

### 工程化

- 迁移为 TypeScript + Vite；核心战斗逻辑（`src/core`）与渲染（`src/platform/web`）分离，便于后续接入微信小游戏。
- 卡牌 / 武将 / 敌人 / 词条数据表迁入 `src/data`。
- 新增 vitest 单元测试、ESLint + Prettier、GitHub Actions CI 与 Pages 部署。
