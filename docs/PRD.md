## 2. 产品概述

### 2.1 一句话定位

**水墨风三国题材的 PVE Roguelike 卡牌微信小游戏**：用三国杀式响应与判定打出策略味，用杀戮尖塔式费用、意图与爬塔打出节奏，用卡厄斯梦境式「战斗中进化 + 局外抄录」打出长期构筑乐趣。

### 2.2 目标用户

| 维度 | 描述 |
|------|------|
| 核心 | 25–40 岁，玩过三国杀/三国题材、或 STS/卡厄斯梦境类 Roguelike |
| 场景 | 通勤碎片时间，单局 15–20 分钟，可断点续玩 |
| 设备 | 中低端安卓与主流 iOS，竖屏单手 |
| 付费 | 不强制付费；广告换便利（复活/刷新/翻倍） |

### 2.3 核心卖点

1. **会「对话」的卡牌战**：杀要闪、锦囊可无懈、判定看花色——不是纯数值对撞。
2. **看得见的敌人意图**：提前规划「这回合挡还是打」。
3. **主将 + 副将**：同一武将可当主可当副，组合多变；珠联璧合有彩蛋。
4. **灵光一闪**：战斗中卡牌当场变强，爽感即时。
5. **兵书抄录**：局内神卡可带到局外，形成个人构筑指纹（非抽卡）。
6. **纯广告免费**：所有武将、卡牌、内容均可玩法产出，零内购。

### 2.4 借鉴对照

| 来源 | 借鉴 | 不借鉴 / 改造 |
|------|------|----------------|
| 三国杀 | 杀闪桃酒、锦囊、装备、花色判定、响应、距离 | 身份局、多人对战、每回合限一杀、体力=手牌上限的严格复刻（手牌上限保留，限杀取消） |
| 杀戮尖塔 | 军令费用、意图、地图节点、三选一奖励、遗物、短局爬塔 | 能量色系统、纯 Block 无响应 |
| 卡厄斯梦境 | 灵光一闪式进化、局外卡牌记忆 | 重度抽卡养成、压力崩溃（V1.0 不做，列入后续） |

### 2.5 产品目标（MVP）

| 指标 | 目标（上线后 30 日） |
|------|----------------------|
| 次日留存 | ≥ 35% |
| 7 日留存 | ≥ 15% |
| 首局完成率（通关引导） | ≥ 70% |
| 通关率（天命 0） | 25%–40% |
| 激励视频人均日展示 | 3–6 次（不强制） |
| 平均单局时长 | 15–20 分钟 |

## 3. 世界观与章节主题

### 3.1 背景故事（玩家可见文案）

史书本应记载三国风云。不知何时，**墨魇**渗入卷页，篡改人名、颠倒胜负。你是**执笔者**，持笔入卷，以武将之魂为墨，重写被污的篇章。  
每一次失败，卷页重新合上；每一次通关，墨魇退去一分——于是你再入下一重难关（天命）。

### 3.2 章节结构（MVP 3 章）

| 章 | 主题 | 氛围 | Boss |
|----|------|------|------|
| 第一章 | 黄巾乱世 | 流民、妖道、黄巾旗帜 | 张角（墨魇化） |
| 第二章 | 讨董烽烟 | 西凉铁骑、洛阳残火 | 董卓（墨魇化） |
| 第三章 | 赤壁江雾 | 水战、火攻、东风 | 曹操（墨魇化·水火双形态） |

每章约 **8 层普通节点 + 1 Boss 节点**。层间有分支（见第 10 章）。

### 3.3 叙事呈现方式

- 章首：1 屏水墨插画 + 2–3 句旁白（可跳过）。
- Boss 前：短对话（主将 vs Boss，≤4 句）。
- 通关：卷轴合上动画 + 结算。
- **不强制剧情任务**，不挡玩法。

## 4. 核心循环

### 4.1 局内循环

```
选主将 + 副将 → 进入第 N 章地图 → 选节点
  → 战斗 / 奇遇 / 营地 / 集市 / 宝箱
  →（战斗胜利）可能灵光一闪 → 三选一奖励
  → 继续地图 → 章末 Boss
  → 下一章 / 通关结算
```

### 4.2 局外循环

```
结算获得将魂 + 武将熟练度
  → 可选：兵书抄录本局进化卡
  → 解锁新武将 / 提升天命
  → 开新一局（可带兵书卡入起始构筑）
```

### 4.3 单局时长预算

| 阶段 | 目标时长 |
|------|----------|
| 选将 | 30–60 秒 |
| 第一章 | 4–6 分钟 |
| 第二章 | 5–7 分钟 |
| 第三章 | 5–7 分钟 |
| 结算 + 抄录 | 30–90 秒 |
| **合计** | **15–20 分钟** |

### 4.4 失败与继续

- 主将体力降至 0 且濒死未救回 → 本局失败。
- 失败可看激励视频**复活一次**（见第 16 章），每局限 1 次（天命≥5 可改为 0 次，见难度表）。
- 任意时刻退游：自动云存档/本地存档，下次从当前节点继续。

## 5. 战斗系统

### 5.1 战场结构

- **玩家侧**：主将（唯一有体力的单位）+ 副将头像（展示技能，不可被选为目标）。
- **敌人侧**：最多 5 个单位，分**前排 / 后排**两排。
  - 前排最多 3，后排最多 2。
  - 若前排清空，后排自动前移成为前排（动画 0.3s）。
- **竖屏布局**：上敌下己，手牌在底部。

### 5.2 距离与攻击范围

| 规则 | 说明 |
|------|------|
| 基础攻击范围 | 1（只能打到「距离 ≤1」的目标） |
| 前排敌人距离 | 对玩家恒为 1 |
| 后排敌人距离 | 对玩家为 2（当前排存在时）；前排清空后变为 1 |
| 武器 | 可增加攻击范围（见装备） |
| 「无视距离」 | 关键词：可选任意存活敌人 |
| 己方目标 | 仅主将（治疗/增益）；副将不可被敌方选中 |

敌人攻击玩家时距离恒视为 1（敌人意图不校验距离，简化 AI）。

### 5.3 资源：军令

| 项目 | 数值 |
|------|------|
| 每回合军令上限 | 3（宝物/技能可改） |
| 回合开始 | 军令回满至上限（不累积未用点，除非有「保留军令」效果） |
| 出牌 | 支付卡牌费用；费用 0 牌可任意打出 |
| 首局默认 | 无额外军令；靠摸牌与费用规划 |

### 5.4 牌堆与手牌

| 规则 | 说明 |
|------|------|
| 抽牌堆 / 弃牌堆 | 抽空则洗弃牌堆为新抽牌堆（保留随机种子，见技术章） |
| 回合开始摸牌 | 3 张；**本场战斗第一回合额外 +2**（共 5） |
| 手牌跨回合 | **保留**（不强制弃光） |
| 手牌上限 | `max(2, 当前体力)`；回合结束时若超上限，需弃至上限 |
| 起始手牌 | 战斗开始前不摸；进入第一回合再摸 |

### 5.5 回合阶段（玩家）

严格顺序状态机：

```
回合开始
  → 触发「回合开始」效果（毒、乐不思蜀类判定、宝物等）
  → 军令回满
  → 摸牌
  → 【出牌阶段】玩家行动（可出牌、可发动主动技、可结束）
  → 回合结束弃牌（若超上限）
  → 触发「回合结束」效果
  → 进入敌方回合
```

**取消「每回合限出一张杀」**：杀仅受军令与手牌限制。

### 5.6 敌方回合

对每个存活敌人按站位顺序（前排左→右，再后排左→右）：

1. 依次打出其**当前意图**中展示的牌（逐张结算，每张【杀】单独进入 5.9.1 响应窗口）。
2. 结算后刷新**下一意图**（按 AI 模式表）。

全部敌方行动完毕 → 玩家下回合。

### 5.7 伤害、护甲、体力

| 概念 | 规则 |
|------|------|
| 体力 | 主将有最大体力与当前体力；归零进入濒死 |
| 护甲 | **回合开始时最多保留 2 点**，超出部分清零（V0.3，防止护甲变成跨回合血池）；受伤先扣护甲再扣体力 |
| 杀基础伤害 | 1（可被酒、技能、进化词条修改） |
| 无攻击力系统 | 任何单位（含敌人）都没有独立攻击力；伤害只来自打出的牌。敌人的【杀】固定 1 点，仅当该牌已灵光一闪进化出对应词条时才改变（如「锋锐」+1、「无影」不可闪、「烈焰」火属性） |
| 伤害来源标记 | 杀 / 锦囊 / 属性 / 体力流失（流失无视护甲） |

### 5.8 属性伤害与铁索连环

| 属性 | 来源示例 | 特殊 |
|------|----------|------|
| 火 | 火杀、火攻类 | 对「铁索连环」状态传导 |
| 雷 | 雷杀、闪电类 | 对「铁索连环」状态传导 |
| 普通 | 普通杀、多数伤害 | 不传导 |

**铁索连环**：
- 单位可处于「连环」状态（图标可见）。
- 当连环单位受到火/雷伤害时，伤害结算后对其他连环单位造成**等额属性伤害**（不再二次传导）。
- 锦囊「连环」可横置/重置（见卡表）。

### 5.9 响应窗口

#### 5.9.1 杀 → 闪

1. 玩家或敌人声明「杀」并选定目标。
2. 进入响应窗口：目标可打出「闪」抵消（玩家从手牌；敌人消耗「闪标记」）。
3. 超时 / 放弃 → 结算伤害。
4. 玩家响应时限：默认 **8 秒**（设置可调 5/8/12）；快速模式见 UI 章。

#### 5.9.2 锦囊 → 无懈可击

1. 锦囊声明目标（或无目标）。
2. 响应窗口：可打出「无懈可击」使该锦囊无效。
3. 无懈可被再无懈（MVP：**最多连锁 2 次**，防拖时长）。
4. 敌人无懈：部分精英/Boss 意图或被动带「无懈标记」。

#### 5.9.3 濒死 → 桃 / 技能

1. 体力≤0 进入濒死，暂停其他结算。
2. 可连续用桃/酒（酒仅自己濒死时可当桃）或回血技能，直至体力≥1 或放弃。
3. 无法救回 → 战斗失败。

### 5.10 判定

1. 从抽牌堆顶亮一张牌（判定牌），展示花色与点数。
2. 按效果判定（如红桃生效 / 黑桃失效）。
3. 判定牌置入弃牌堆。
4. 改判：若有效果「可打出某牌替换判定牌」，在亮牌后、结算前插入一次选择。

### 5.11 装备区

主将装备区 4 栏：

| 栏位 | 数量 | 说明 |
|------|------|------|
| 武器 | 1 | 加攻击范围 / 杀相关效果 |
| 防具 | 1 | 闪避或减伤类 |
| +1 马 | 1 | 他人与你距离 +1（防御） |
| -1 马 | 1 | 你与他人距离 -1（进攻） |

替换：新装备进入时旧装备弃置。敌人可有简化装备（作为意图/被动展示，不完整四栏）。

### 5.12 敌人意图系统

#### 5.12.1 意图 = 敌人本回合要打出的牌

意图不再显示伤害数值，而是直接显示敌人本回合将打出的牌及张数（如 `🗡杀×2`、`🗡杀[锋锐] 🗡杀`、`🛡闪`）。敌人的牌为**虚拟牌**（不进入任何牌堆，不可被获得/弃置）。

| 意图牌 | 图标 | 效果 |
|--------|------|------|
| 杀 | 刀 | 对玩家造成 1 点伤害；玩家可用闪响应 |
| 杀[词条] | 刀+墨迹角标 | 已灵光一闪进化的杀，按词条结算（锋锐：2 点；无影：不可闪；烈焰：火属性……） |
| 万箭齐发 | 箭雨 | 1 点伤害，不可闪（对应原「重击」类） |
| 闪（备闪） | 盾 | 获得 1 枚闪标记（取代原「防御 N 护甲」） |
| 减益锦囊 / 咒 | 箭下 | 给玩家 Debuff / 弃牌（如「咒·弃1」） |
| 召唤 | 人+ | 召唤小怪 |
| 特殊 | ？ | 读条技能、变形态 |

- 一个意图可包含多张牌，按显示顺序结算。
- 敌人护甲**只来自技能/特性**（如开场护甲、被动加甲），不来自意图。
- 意图悬浮/长按提示显示「预估总伤害」= 各张牌伤害之和（供 19.5 致命描边使用）。

**杀的响应**：玩家可对敌人每张杀响应闪；敌人若无「闪标记」则无法闪玩家的杀。

#### 5.12.2 闪标记

- 部分敌人回合开始时获得 0–2 枚闪标记。
- 被杀时自动消耗 1 枚抵消（无需 AI 决策）。
- 标记数在敌人头顶显示。

#### 5.12.3 AI 模式（配置字段）

每个敌兵配置：

```
intentPattern: [["杀"], ["闪"], ["杀","杀"]]  // 每回合打出的牌，循环
cardMods: { "杀+": ["E_S01"] }                  // 已进化的牌（词条见 8.5）
# 或
intentAI: "weighted"
weights: { "杀":40, "杀×2":20, "闪":25, "咒":15 }  // 按意图组合加权
hpBranch: { "below50%": "ENRAGE" }  // 阶段切换
```

MVP 优先用**固定循环 + 低血阶段切换**，加权随机用于少数精英。

### 5.13 战斗胜利 / 失败

- 胜利：场上无存活敌人。
- 失败：主将死亡且未复活。
- 胜利后：触发灵光一闪检测（第 8 章）→ 奖励界面（第 14 章）。

### 5.14 战斗内可选项

| 选项 | 说明 |
|------|------|
| 结束回合 | 明确按钮，防误触二次确认（可设置关闭） |
| 查看意图详情 | 点敌人弹出本回合出牌列表、每张牌效果（含进化词条）、预估总伤害、是否可闪 |
| 查看牌堆 | 抽牌堆仅显示剩余张数；弃牌堆可查看列表 |
| 自动出闪 | 设置项：被杀时若有闪自动打出 |
| 跳过动画 | 设置：战斗动画速度 1x/1.5x/2x |

## 8. 灵光一闪

### 8.1 设计目标

战斗中打出牌时，有概率让**正在结算的那张牌的牌组实例**进化：附加一条词条（三选一）。即时爽感 + 构筑差异。

### 8.2 触发时机

- 监听：玩家**打出并成功结算**的牌（被无懈的锦囊不触发；被闪的杀不触发）。
- 装备牌：装备成功进入装备区时判定。
- 闪：成功抵消杀时判定。

### 8.3 概率与保底

| 项目 | 数值 |
|------|------|
| 基础触发率 | 8% |
| 每场战斗最多触发 | 2 次 |
| 软保底 | 本场累计打出 12 张未触发 → 下一次必触发（仍受每场上限限制） |
| 章节修正 | 第 2 章 +2%，第 3 章 +3%（仅基础率） |
| 宝物可改 | 如「墨灵笔」+5% 等 |

伪代码：

```
onCardResolved(card):
  if battleEpiphanyCount >= 2: return
  if roll(rate) or softPity: openEpiphanyUI(card)
```

### 8.4 UI 流程

1. 暂停战斗表现，弹出「灵光一闪」层。
2. 展示当前卡牌 → 三个词条候选（名称+描述）。
3. 玩家点选一条 → 该牌实例写入 `modifiers[]`。
4. 可选：看广告刷新词条一次（第 16 章）。
5. 关闭后继续战斗。

### 8.5 词条库

按牌类型过滤；同稀有度权重：N 50% / R 35% / E 12% / L 3%（先抽稀有度再抽词条）。

## 9. 兵书存档

### 9.1 设计目标

把「这一局灵光一闪出来的神卡」有限度带入未来开局，形成长期个性构筑；**不是抽卡**，而是玩出来的收藏。

### 9.2 抄录时机

- 任意一局**胜利或失败结算后**，若本局存在进化过的卡牌实例，进入「兵书抄录」可选界面。
- 可跳过。

### 9.3 墨值与容量

| 项目 | 数值 |
|------|------|
| 初始墨值上限 | 6 |
| 提升 | 熟练度、成就、天命通关奖励（最高 12） |
| 抄录消耗 | 按卡稀有度 + 词条稀有度合计 |

**单卡墨值消耗**：

```
cost = base(card.rarity) + sum(mod.rarity)
base: N=1, R=2, E=3, L=4
mod:  N=0, R=1, E=2, L=3
```

例：普通杀 + 锋锐(N) + 穿杨(R) = 1+0+1 = 2 墨值。

### 9.4 兵书栏

- 全局共享一个兵书列表（不限武将），但开局时：
  - 仅可打入**当前主将可用**的卡（专属需匹配主将或副将）。
  - 每局限从兵书**带入 0–2 张**（天命≥3 起可带 3，配置）。
- 带入的卡**加入起始牌组**（可超过默认张数，但若总牌>15，开局强制选择删除至 15）。

### 9.5 替换与删除

- 兵书已满墨值时，抄录需先删除旧卡腾出墨值。
- 可随时在局外「兵书」界面删除（不退将魂）。

### 9.6 平衡约束

| 约束 | 说明 |
|------|------|
| 不可抄录 | 宝物、丹药、临时生成的「消耗」牌 |
| 弱化 | 抄录卡进入新局时，保留词条，但 **L 级词条在天命 0–1 降为 E 效果**（可选，防碾压）——MVP 可先不做降级，靠墨值限制 |
| 唯一 | 同名同词条组合仅能存 1 份 |
| 广告 | 结算时可看广告额外抄录 1 张（仍耗墨值，若不足则仅允许墨值≤2 的卡） |

### 9.7 数据字段

```
BingshuEntry {
  id, cardId, modifiers[], costInk,
  fromHeroId, createdAt, winRateSnapshot
}
```

## 16. 广告设计

### 16.1 原则

- 纯激励视频，**无强制插屏打断战斗**。
- 所有内容不靠广告解锁；广告 = 便利与加倍。
- 新手前 2 局：广告入口可见但提示「可跳过」。

### 16.2 点位

| 点位 | 触发 | 奖励 | 频控 |
|------|------|------|------|
| 复活 | 主将死亡 | 回 25% 体力并获得 3 护甲，清空敌人当前意图改为「闪」 | 每局限 1；天命≥5 关闭 |
| 奖励刷新 | 三选一卡牌 | 刷新候选 | 每节点 1 次 |
| 灵光刷新 | 灵光三选一 | 刷新词条 | 每次灵光 1 次 |
| 商店刷新 | 集市 | 免费刷新 | 每进店 1 次 |
| 营地扩展 | REST | 增加第三选项 | 每章 1 次 |
| 结算翻倍 | 结算屏 | 将魂 ×2 | 每日最多 3 次 |
| 额外抄录 | 兵书 | 额外抄 1 张 | 每结算 1 次 |
| 每日补充 | 每日挑战入口 | 额外将魂 +10 | 每日 1 次 |

### 16.3 频控与体验

- 全局：两次激励之间间隔 ≥30 秒。
- 失败重试加载：loading 可自然塞预加载，不自动播放。
- 广告失败（无填充）：给予「冷却 5 分钟后视同观看」的弱补偿仅用于复活外的刷新类；**复活不补偿**。

## 18. 新手引导

### 18.1 目标

首局 3–5 分钟内教会：出杀、出闪、军令、意图、地图选点。

### 18.2 脚本首局（强制一次，可跳过二次确认）

1. **选将锁定**：主将赵云，副将关羽（珠联演示）。
2. **战斗教程 1**：单敌人黄巾步卒；强制手牌含杀、闪；引导出杀 → 敌人攻击 → 引导出闪。

5. **灵光**：脚本必触发一次（杀进化）。
6. **营地**：引导疗伤。
7. **Boss 前**：可跳过长对话；击败弱化张角（HP 14）。
8. **结算**：引导打开兵书抄录。

- 首次精英、首次商店、首次广告点位：气泡 1 次。

## 21. 技术需求（引擎无关）

### 21.1 架构

```
Presentation（UI/动画） 
    ↕ 事件
GameLogic（纯确定性：战斗/地图/随机）
    ↕
Config Tables + RNG(seed)
    ↕
Save / Net / Ads Adapter
```

- **逻辑层禁止读时间/随机无种子 API**。
- 表现层可插值动画，不改变逻辑结果。

### 21.2 确定性 RNG

```
class SeededRNG {
  next(): number        // [0,1)
  shuffle(arr)
  weightedPick(items)
}
streams: map / combat / reward / epiphany 分流，避免一处消耗影响另一处。
```

### 21.3 效果与触发器

建议结构：

```
CardEffect / SkillEffect
Buff { id, stacks, duration, hooks }
Trigger: OnTurnStart, OnPlayCard, OnDamage, OnDying, OnJudge...
Pipeline: 声明 → 响应窗口 → 结算 → 死后触发
```

响应窗口状态机：`IDLE → WAIT_DODGE → WAIT_NULLIFY → RESOLVE`。

### 21.4 断点续玩存档

```
RunSave {
  version, runSeed, chapter, mapState,
  heroMain, heroSub, hp, maxHp, gold,
  deck[], relics[], potions[], bingshuTaken[],
  nodePath[], battleState?(nullable),
  tianming, timestamp
}
```

- 战斗中退出：保存 `battleState` 完整快照（牌堆顺序、手牌、敌人意图索引、Buff）。
- 进战斗节点时先写盘再播动画。

### 21.5 配置表

- 格式：JSON 或 Excel→JSON。
- 热更：微信 CDN 分包配置（审版本策略允许前提下）。
- Schema 见附录。

### 21.6 微信包体

| 项 | 目标 |
|----|------|
| 主包 | ≤ 4MB |
| 分包 | 按章/图鉴/音频拆分 |
| 总包 | 尽量 ≤ 30MB 首期 |
| 首屏 | ≤ 3s 可点（中端机） |

### 21.7 性能指标

| 项 | 目标 |
|----|------|
| 战斗帧率 | ≥ 50 FPS（中端） |
| 同屏敌人 | ≤ 5 |
| 手牌 | ≤ 12 正常；>12 缩卡 |

### 21.8 防作弊

- 结算校验：服务端按 `runSeed + 操作日志` 重放抽查（MVP 可先做将魂上限与异常检测）。
- 操作日志：关键随机点与选牌 hash。
- 广告回调以媒体服务器为准。
