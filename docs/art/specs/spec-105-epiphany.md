# 视觉规格 · #105 灵光一闪弹层

> 规则口径：`docs/specs/subpages-v05.md` §1；渲染口径：`docs/ui/render-spec.md` §4 页面表「灵光一闪」、§5、§8.6、§10.1、§11 #8。本文只补**视觉落地数值**，与上述文档冲突时以规则文档为准，并回报 UI。
> 画风：style-C 水墨扁平（`docs/art/style-C-flat-ink.md`）。示意图：`mock/spec-105-default.png`、`mock/spec-105-full.png`（及 `-gray`），由 `mock/render-mocks.mjs` 生成，**只作示意**，数值以本文为准。
> 配色 token 均指 `src/game/scenes/p4-kit.ts` 的 `T.*`；字体 `BRUSH()` = 霞鹜文楷，数字用位图数字（§2 `num-*`）。

## 4. 动效（时长不受倍速影响：弹层期间战斗暂停，§8.6）
| 段 | 时间 | 内容 | 缓动 |
|---|---|---|---|
| 触发·墨聚 | 0–600ms | 遮罩 α 0→1（0–200ms）；墨气向大牌中心旋转汇聚（§11 #8，WebGL 关时用 2D 回退） | inOut |
| 触发·金光 | 600–900ms | 金光贴图缩放 0.6→1.2 后淡出；大牌 0.8→1 | back |
| UI 入场 | 700–1000ms | 标题、次数淡入 200ms；候选面板自下 16px 上移 + 淡入，每条 220ms，错开 60ms；`#full` 已有行先于候选 60ms | out |
| 可操作 | 从 900ms 起 | 入场未完成也可点（点到的面板直接到终态） | — |
| 选中 / 换目标 | 120ms | 描边与发光淡入；切换选择时旧的 80ms 淡出 | out |
| 铭刻 / 替换 | 300ms | 新词条名缩小飞入大牌词条位；`#full` 时被替换词条同时化墨淡出 250ms | inOut / out |
| 退场 | 200ms | 全部 α→0，战斗恢复；放弃同样 200ms 退场 | out |
- 触发 900ms 阻塞（§10.1），**点击跳过**：直接跳到 UI 入场终态。
- `prefers-reduced-motion`：不播墨聚与金光，遮罩 + UI 一起 150ms 淡入；飞入改为 150ms 交叉淡化。
- 低画质 / WebGL 关：墨聚走 2D 回退；不加任何循环特效（弹层内无常驻循环动画）。

## 5. 交互要点（视觉相关）
- 默认态未选时「铭刻」disabled；`#full` 新词条和替换目标都选中前「替换」disabled；「放弃」始终可点。
- 热区：候选面板整块；已有词条行整块；按钮按 §4.0 补足 44×44；相邻热区不重叠（已有行两块间距 12，热区不外扩到相邻块）。
- 杀进程重进：恢复同一组候选、已选状态清空、不重播墨聚（直接到终态，遮罩 150ms 淡入）。

## 6. 可读性（70 灰）
- 用灰度示意图 `mock/*-gray.png` 自查：标题、词条名（paper 对深漆，亮度差 >180）在灰度下清晰。
- **稀有度颜色在灰度下分不开**：E `#E9C877` ≈ 灰 201，L `#9AD4B8` ≈ 191，只差约 10 级；N ≈ 161、R ≈ 228。因此菱形必须用 §3 的形状编码，不能只靠颜色。
- **替换目标不能只靠朱砂描边**：灰度下朱砂描边与普通金描边接近；「替」角标 + 删除线必须同时出现。
- 选中候选靠 goldHi 描边 + 外发光，灰度下仍是最亮的一块，可辨。

## 7. 与现有界面的关系（不冲突处）
- 不改战斗页 §7.1 任何层的绘制，只在其上加 z10–13；遮罩压住手牌，手牌不可点。
- 与响应弹层（遮罩 `rgba(5,2,1,.72)`）不同时出现（见 §2）；与 dying 红边脉动、致命徽章脉动不冲突：二者在 z≤12 的战斗层，被遮罩压暗，**循环继续**但不抢焦点。
- 微信胶囊：次数是非交互元素，可以在胶囊区之外绘制；与胶囊相交时按 §1 下移。
- 与营地「淬炼 · 替换」（§8.7）保持同一视觉语言（替换目标、放弃文案），但灵光一闪是全屏遮罩，不是居中面板。
