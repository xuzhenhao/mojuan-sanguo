# 战斗界面竞品研究：杀戮尖塔 / 三国杀 / 卡厄思梦境

> 目的：v1 的四版方案被否，原因是“字太多、不知道看哪，同时又显得简陋”。这份研究给 v2 定方向。

## 1. 杀戮尖塔（Slay the Spire）
- **信息层级**：画面只回答三个问题：敌人下回合打我多少（意图）、我还剩多少（血+格挡）、我能出什么（手牌+能量）。其余信息（遗物、药水、牌堆）缩在边缘的小图标里。
- **视觉焦点**：敌人头顶的意图图标最抢眼，用“图标+数字”表示，例如剑 12、剑 5×3；图标形状区分攻击/防御/增益/未知，**不写字**。
- **角色**：横版舞台，角色有完整立绘并站在地面上；血条贴在脚下，格挡是一面蓝盾压在血条左端。
- **卡牌**：扇形手牌；左上角是能量宝石，中间是插画，牌框颜色和外形区分攻击/技能/能力。描述文字要放大或悬停才读，平时只看插画和费用。
- **能量**：左下角发光的大圆球，写“3/3”，是全屏第二亮的元素。
- **交互**：把牌拖到目标上出牌；拖动时画出指向箭头，合法目标亮起。悬停或长按查看关键词。
- **启示**：意图要“图标+大数字”，致命意图用强色；常驻文字能删就删；能量和血量要做成发光的实物感 UI。

## 2. 三国杀（移动版/十周年）
- **信息层级**：武将牌是信息中心，包含头像、名字（竖排书法）、势力、体力（勾玉）。手牌在底部一字排开，花色点数在左上角。
- **视觉焦点**：主要靠华丽的边框（金边、雕花、势力配色）和人物立绘撑质感；出牌时以“指向线+目标框高亮”为焦点。
- **响应**：最有辨识度的范式是“请出闪”提示横幅 + 倒计时进度条 + 确定/取消按钮 + 合法手牌上浮、非法手牌压暗，玩家已经形成肌肉记忆。
- **判定**：判定牌在中央翻面，结果用印章标出（生效/失效）。
- **启示**：①竖排书法名字和金色牌框是“精致感”的捷径；②勾玉体力天然少字；③响应窗口直接沿用三国杀范式，学习成本为零。

## 3. 卡厄思梦境（Chaos Zero Nightmare）
- **信息层级**：左边是我方（全队共享血条、压力、资源），右边是敌人，底部是 AP 和手牌。图标非常多，但都用圆形徽章统一包装，点开才看说明。
- **敌人**：每个敌人都有“行动倒计时”数字（我方每出一张牌就减 1，归零立即行动），加上预告行动图标、弱点属性、血条、韧性格。行动时机可视化，是它的核心创新。
- **卡牌**：插画占满整张牌，费用在角上，属性用小图标表示；灵光一闪就绪的牌带流光边。
- **质感**：二次元厚涂立绘，配上镜头、光效和粒子；UI 采用半透明玻璃加描边。
- **启示**：①“灵光一闪”用流光边+角标，对应我们的“墨”；②行动倒计时可以选用（方案 B 演示）；③所有说明都收进“点按/长按”。

## 4. 对《墨卷三国》的结论
| 要点 | 做法 |
|---|---|
| 一眼可读 | 只常驻 4 类信息：我方体力/护甲、敌方意图、手牌、军令 |
| 去文字 | 意图=图标+数字；卡牌只留 1–2 字书法名+费用+花色；说明全收进长按 |
| 精致感 | 写意立绘/剪影 + 鎏金或墨漆牌框 + 宣纸/漆面材质 + 光影（发光、投影、晕染） |
| 焦点 | 致命意图朱砂脉冲；军令砚台/令牌发光；响应时全屏压暗，只亮“攻击者→我→合法牌” |
| 响应 | 三国杀范式：横幅/环形倒计时 + 合法牌上浮 + 承受伤害预览 |
