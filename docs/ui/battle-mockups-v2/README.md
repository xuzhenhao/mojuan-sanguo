# 战斗页 v2 方案（水墨 · 去文字 · 精致质感）

在线预览（Pages 部署后）：`/mojuan-sanguo/mockups/v2/index.html`。每页支持以下 hash：`#resp` 响应弹层，`#detail` 长按详情，`#target` 选目标。
截图在 `screens/`。v1（PR #10）只作为反面参照。

## A 墨卷长轴（参考杀戮尖塔）
宣纸山水长卷当舞台，敌人是站在台上的水墨剪影，头顶只有“图标+数字”的意图气泡，致命意图用朱砂脉冲；我方是大立绘配红心体力和蓝盾护甲，军令是左下角发光的砚台，手牌扇形排开，每张只写两字书法名。
**层级**：①致命意图（唯一的红色光源）→②我方红心/护甲→③军令砚台→④手牌。其余信息（牌堆、丹药、回合、铜钱）缩成小图标贴边。
**响应**：全屏墨色压暗，只亮攻击者、我方和两张合法牌；红色虚线把攻击者指向我；环形倒计时里放一个“闪”图标，旁边是承受预览“❤−4”，不需要写一句话。

## B 金漆屏风（参考三国杀 + 卡厄思梦境）
黑红漆面底配回纹格栅，敌人和我方都画成鎏金框的武将牌（竖排书法名、勾玉体力），敌人左上角是卡厄思式的行动倒计时圈；军令用三枚鎏金虎符表示，判定区在中央翻牌并盖印。
**层级**：①Boss 牌最大、意图发红光 →②右下角我的武将牌（勾玉+护甲）→③左侧虎符军令 →④底部手牌。
**响应**：采用三国杀范式，即“出闪”横幅 + 进度条 + 确定/承受(❤−4)；合法牌上浮发金光，其余压暗；弧形红箭从张郃指向赵云。

## 共同规则
- 卡牌只常驻：费用、花色点数、插画、两字名；“墨”是灵光一闪角标并配流光。
- 长按卡牌、敌人或意图弹出详情卡；点牌→点目标，或拖拽出牌。
- 立绘和插画目前是 SVG 程序化水墨剪影，供定方向用；正式美术按 render-spec 规格替换为写意半身像。
