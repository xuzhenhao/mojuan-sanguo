# 墨卷三国 · 原型难度分析与调整方案（策划提案）

> 状态：**已采纳（2026-10-12，写入 PRD V0.3；实施见 issue #1）**。提案阶段未修改 PRD.md。数据来源：`mojuan-sanguo/src/data/*`、`src/core/*`、PRD 5.x / 11.x / 25.3（O8–O10）。
> 前提（已定）：没有攻击力，伤害全部来自卡牌；敌人的杀打 1 点（灵光一闪进化除外）。

## 0. 现状数据

| 项 | 数值（原型） |
|---|---|
| 玩家 | 关羽 8 体力；每回合 3 军令，摸 3 张（首回合 +2）；手牌上限 = max(2, 体力) |
| 龙虎会 | 开场 3 护甲；护甲**没有回合末清零**（代码里只在开场设置） |
| 牌组 | 19 张：闪 ×2、桃 ×1、以逸待劳（+5 护甲）×1、八卦阵 ×1；红色牌 11/19 ≈ **58%** |
| 判定 | 护主：每回合第 1 张杀判一次，红色则无效；八卦阵：每张杀判一次，红色视为闪 → 单次判定成功率约 58% |
| 敌人 | 步卒 3 血 [杀]/[杀杀]；弓手 2 血 [杀]/[杀]/[闪]；咒师 4 血 [咒]/[杀]；暴徒 5 血 [杀杀]/[杀]/[杀杀杀]；张宝 12 血 [杀+ 杀]/[闪 杀 杀]/[万箭 杀+ 杀+]（杀+=2） |

## 1. 根本原因（机制层面）

### 1.1 输入伤害太低，而且随着敌人死亡迅速衰减
- 黄巾前哨首回合预期敌方出杀 ≈ 1.5+1.5+0.67 = **3.7 张**（=3.7 点），流民之乱 ≈ 2+1.5+0.5 = **4.0**，张宝战 ≈ 4.7（含杀+和弓手）。
- 但玩家每回合大约能打出 3 点（3 军令，酒/义勇/武圣斩再加 1–2），敌人总血量只有 8–14。**第 2 回合起前排敌人就开始死**，输入伤害降到 1–2 点。真正「满输入」的只有 1–2 个回合。
- PRD 第 11 章给的每回合敌方合计伤害（第 1 章 3–5 点）是所有敌人**都活着**时的值，没有算进玩家的击杀速度。

### 1.2 防御资源叠加层数太多，每层都按「张数」抵消，而每张杀只值 1 点
以首回合 3.7 张杀为例，算每一层的预期抵消：

| 防御层 | 预期抵消/回合 | 说明 |
|---|---|---|
| 护主 | ≈0.58 | 每回合第 1 张杀，58% 红色 |
| 八卦阵（装上后） | ≈剩余杀 ×0.58 | 首回合 2.7 张 → ≈1.6 |
| 手牌闪 | ≈0.3–0.5 | 2/19 的密度 × 每回合 3–5 张；0 费，不占军令 |
| 护甲 | 开场 3 + 以逸待劳 5（约每 4 回合轮到一次）≈ 首回合 3、平均每回合 ≈1.25+ | **跨回合保留**，相当于一个血量池 |
| 桃 | ≈0.16 | |

- **没装八卦阵**：3.7 − 0.58 − 0.4 ≈ 2.7 点进护甲，开场 3 护甲就能吃掉首回合全部伤害。
- **装上八卦阵**：进到护甲层的约 1.1 点/回合。
- 结论：**普通战每回合预期掉血 ≈ 0**。前 1–2 回合全部被护甲吸收，之后敌人数量减少，输入又低于抵消。这和试玩里 7/8、8/8、8/8 的结果一致。

### 1.3 护甲跨回合保留 + 护甲牌数值按旧攻击力设计（O8）
- 以逸待劳 5、金创药 10、固守 6 这些数值是按「敌人一下打 3–6 点」定的。改成 1 点杀之后，**1 张以逸待劳 ≈ 5 张杀**，大约是一个普通敌人 2–3 回合的全部输出。
- 护甲不清零，所以没有「这回合必须防」的节奏：护甲会一直攒，敌人的爆发回合（暴徒的杀×3、张宝的万箭+杀+×2）都会被提前存下的护甲吃掉。

### 1.4 判定类防御的期望值太高，而且是被动的
- 护主和八卦阵都是 0 费、不占手牌、自动生效。牌组 58% 是红色（关羽的武执/武圣斩需要红牌，所以牌组本来就偏红），**连带抬高了判定成功率**。
- 八卦阵 + 护主 + 闪，等于每张杀都要过 3 道关。1 点杀的设计本意是「多段、可响应」，但响应窗口变成了全自动免伤。

### 1.5 敌人出牌数和攻防节奏
- 敌人每回合 1–3 张，平均 1.5 左右。三分之一的意图是空回合（闪/咒）。
- 敌人的闪标记（弓手、咒师、张宝）只会拖慢玩家，**不会形成威胁**，所以战斗回合数拉长（流民之乱 19 回合），但并没有更危险。拖长反而让玩家把以逸待劳/桃都轮到，满血收尾。
- 唯一能破防的是「万箭」（不可闪），只在张宝第 3 个意图出现，而且只有 1 点。

### 1.6 体力也是资源，却没有被消耗
- 手牌上限 = 体力，满血 = 手牌上限高，又反过来强化防御（能存更多闪），形成正反馈。

## 2. 可选方案

### 方案 A：护甲回合末清零 + 护甲牌数值下调（直接解决 O8）
**改动**
- 护甲在**玩家回合开始时清零**（杀戮尖塔式）；龙虎会改成「每场首回合 +2 护甲」或「每回合首次受伤 -1」。
- 护甲牌按 1 点杀重新定价：以逸待劳 5→2（或「2 护甲 + 摸 1」）、固守 6→2、金创药 10→3（或回 1 体力 + 2 护甲）、七进七出 7→3。词条「坚固 +3」→+1，「回春 +3」→+1。
- 换算原则：**1 军令 ≈ 抵 2 点伤害 ≈ 打出 2 点伤害**。

**体验影响**：每回合都要在「打」和「防」之间做决定，敌人的意图（杀×3）真正变成威胁提示。护甲不再是长期血池。
**与灵光一闪**：护甲类词条要同步下调，否则会变成新的「必选」。敌人的杀+锋锐（2 伤）相对价值上升，进化敌人的威胁更明显，这是好事。
**与天命**：天命层可以再叠「护甲减半」这类修饰，不必只靠加杀。
**与广告复活**：死亡率上升，复活的使用率会自然提高；要确认复活后有护甲或免伤回合，否则复活即死。
**风险**：改动面大（第 5.7、6.6、7.4、8.5 都要改），护甲牌可能变得不好用；需要重新做护甲牌价值曲线。

### 方案 B：提高敌方出牌数/密度（加输入，不动玩家防御）
**改动**
- 普通敌人意图平均从 1.5 张提到 2–2.5 张：步卒 [杀杀]/[杀杀杀]，弓手 [杀杀]/[万箭]/[闪 杀]，暴徒 [杀杀杀]/[杀杀]/[杀杀杀杀]。
- 每场普通战首回合合计 5–7 张，保留 1 张「万箭」类不可闪。
- 敌人血量 +30–50%（步卒 3→4、暴徒 5→7、张宝 12→16），避免玩家第 2 回合就清场。

**体验影响**：意图栏更「热闹」，响应窗口更多；但每张杀都要弹响应窗口，**单回合时长拉长**（8 秒×多张）。
**与灵光一闪**：玩家的闪词条（余韵、反震）收益上升，形成新的流派，正向。
**与天命**：天命 4 现在是「每个带杀的意图多 1 张杀」。B 方案之后基础值已经高了，天命叠加可能过量，需要重新标定。
**与广告复活**：影响不大。
**风险**：只加数量不解决「护甲跨回合 + 判定免伤」的叠层问题，玩家拿到八卦阵后难度还是会塌；操作疲劳；和 PRD 11 章的「每回合 3–5 点」冲突，要改表。

### 方案 C：限制判定类免伤和闪的供给
**改动**
- 护主：改成「每场限 2 次」或「判定 ♥ 才无效」（25%），而不是红色（≈50–58%）。
- 八卦阵：改成「每回合限 1 次」。
- 闪：手牌闪改成 1 费（或维持 0 费，但响应窗口每回合限出 2 张）；起始牌组闪 ×2 不变。
- 赵云龙胆（杀当闪）实装时也算入这个上限。

**体验影响**：判定从「几乎必中的被动」变成「偶尔救命」，更有惊喜感；防御更多依赖主动出牌。
**与灵光一闪**：闪类词条价值不变；八卦阵可以加一条「坚韧：每回合判定次数 +1」这种进化词条，作为成长目标。
**与天命**：可以把「判定改为仅 ♥」作为天命修饰，留出难度梯度。
**与广告复活**：影响小。
**风险**：削的是武将特色（赵云/八卦阵是三国杀标志性体验），玩家感知是「被削」；单改这个只能降低大约 1–1.5 点/回合的抵消，护甲仍然能兜底。

### 方案 D：组合方案（A 的轻量版 + B 的轻量版 + C 中的护主）——推荐
**改动**
1. **护甲：每回合开始时保留至多 2 点**（超出部分清零）。比完全清零温和，龙虎会开场 3 护甲依然有意义。
2. **护甲牌下调**（解决 O8）：以逸待劳 5→3，固守 6→3，金创药 10→4，七进七出 7→3；坚固/回春 3→2。
3. **敌人密度**：普通敌人的意图平均 +0.5 张，每个敌人 3 个意图里至少 1 个 ≥2 张杀；血量 +1–2（步卒 4、弓手 3、咒师 4、暴徒 6；张宝 15）。精英每轮 1 次「万箭」或 2 张杀+。
4. **护主改成每回合判定一次，「♥/♦ 中仅 ♥ 有效」**（约 30%），八卦阵维持原样（装备本身要花 1 军令 + 抽到，保留爽点）。
5. 结合 O9：张角雷判定、火船自爆改成虚拟锦囊牌（闪电/火攻），统一走卡牌通道，玩家可以用无懈/判定来应对，口径一致。

**体验影响**：首回合进伤约 2–3 点，每回合必须决定防不防；满血通关普通战变少，但不会频繁暴毙。
**与灵光一闪**：玩家侧护甲词条一起下调；敌人锋锐进化（2 伤）变成精英/Boss 的特征威胁，和玩家灵光一闪对称。
**与天命**：基础难度定位在「天命 0」，天命 1–4 依次叠：敌血 +10% → 护甲保留 0 → 护主仅 ♥ 改成每场 2 次 → 每个带杀意图 +1 杀（原天命 4 保留）。
**与广告复活**：Boss 战死亡率预期 15–25%，复活有实际价值；复活后给 3 护甲 + 本回合敌人跳过 1 张杀，避免复活即死。
**风险**：多参数同时改，难以归因。建议按 ①②→③→④ 分三轮做 A/B 试玩，每轮用自动试玩跑 ≥200 场看分布。

## 3. 推荐：方案 D（分步实施）

理由：
1. **问题是多层叠加导致的，单改一层不够**。A 只解决护甲，B 只加输入，C 只削判定；按 1.2 的表，每层单独去掉，其余层仍能把每回合掉血压到 0 附近。
2. **护甲跨回合保留 + 护甲牌数值过高（O8）是最大的单一因素**（首回合能吃掉 3–8 点），优先改。D 用「保留至多 2 点」而不是完全清零，保住龙虎会的组合感和三国杀「藏防具」的感觉，改动成本最低。
3. **加敌人密度/血量**是为了把「满输入回合」从 1–2 回合拉长到 3–4 回合，让防御资源真正被消耗，同时不打破「杀=1 点」的已定规则。
4. 护主只削判定花色、不删技能，保留赵云的特色；八卦阵作为「装备成本 + 抽到运气」的奖励保留。
5. 顺带解决 O8、O9；O10 建议采用「从意图杀预支」，与 D 不冲突。

**实施顺序**：第 1 轮 ①② → 第 2 轮 ③ → 第 3 轮 ④ ⑤。每轮对照第 4 节的指标，达到就停。

## 4. 目标指标建议（天命 0，关羽+赵云起始牌组，8 体力）

| 战斗类型 | 结束剩余体力（中位数） | 分布要求 | 回合数 | 战败率 |
|---|---|---|---|---|
| 普通战 | **5–6 / 8**（掉 2–3） | 满血结束 ≤15%；≤3 体力 ≤10% | 4–7 | <2% |
| 精英战 | **3–5 / 8**（掉 3–5） | 满血结束 ≤5% | 6–9 | 5–10% |
| Boss 战 | **1–4 / 8** | 至少 1 次进入濒死窗口的比例 ≈30% | 8–12 | 15–25%（广告复活能救回一半以上） |
| 整章（第 1 章） | 打到 Boss 时的体力 4–7（含途中回复） | | | 通关率 60–70% |

过程指标：
- 首回合敌方预期出杀 4–6 张，玩家预期掉血 1–2；每回合「至少受 1 点伤害」的回合占比 ≥50%。
- 护甲来源里，开场/保留护甲占比 ≤40%（避免回到血池玩法）。
- 防御牌（闪/护甲/桃）打出占比 25–35%，进攻 50–60%：有攻防取舍。
- 天命每升 1 级，Boss 剩余体力中位数降约 0.5–1，战败率 +5%。

测量方法：在自动试玩里每种战斗跑 ≥200 场（固定种子 + 随机种子），记录剩余体力分布、回合数、每层防御的抵消量（护主/八卦/闪/护甲/桃分别统计），用来验证 1.2 表里的估算。
