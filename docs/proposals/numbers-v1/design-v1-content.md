# 《墨卷三国》V1 全量内容表

> 依据 design-v1.md 第 2 节的价值模型。记号：令 = 军令（1.5 点）；牌 = 占 1 张手牌（1.0 点）；甲 = 护甲（0.8 点）；体 = 体力（1.5 点）；P(红) = 0.5、P(♥) = 0.25（独立签筒）。
> **净值 = 效果点数 − 1.5 × 费用 − 1.0**（占牌）。净值目标：N −0.5~0 / R 0~+0.5 / E +0.5~+1 / L +1.5~+2；专属牌比同稀有度再高 0.5。
> 「改」= 相对 PRD 6.6 的数值或文本修改；「新」= 新增。被动免伤一律受配额限制（每敌方回合 2 次，见 design-v1.md 2.4）。
