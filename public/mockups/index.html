《墨卷三国》核心战斗页 UI 方案

390×844 竖屏静态稿。点卡牌→点前排目标；右上「响应」切换响应窗口。示例：主将赵云 + 副将刘备。

  • A · 宣纸卷轴 (响应弹层)

    宣纸米白底配焦墨描边与朱砂印章，晕染纹理还原传统卷轴质感，交互以“点卡—墨晕高亮目标”为主，信息层级最克制易读。

  • B · 夜墨金石 (响应弹层)

    以焦墨夜色为底、宣纸白字与朱砂/鎏金点缀，石刻碑拓纹理营造夜战压迫感，交互重点是致命意图红光描边与响应倒计时的紧张节奏。

  • C · 青绿山水 (响应弹层)

    淡青与石绿为主调的山水长卷，柔和留白与圆润卷轴卡框带来清雅的策略感，交互重点是前后排的远近景层次与扇形手牌的舒展浏览。

  • D · 剪纸朱砂 (响应弹层)

    朱砂红与焦墨的高对比剪纸拼贴，硬边投影与锯齿纸缘带来强烈节奏感，交互重点是大字号花色（形状+文字双编码，色弱友好）与粗按钮的拇指操作。
