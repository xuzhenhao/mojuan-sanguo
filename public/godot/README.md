# Godot 引擎手感验证切片

墨卷三国玩法的 Godot 4.7 Web 垂直切片（点将 → 单敌一局 → 结算）。

- 导出：Godot 4.7.2 Web **无线程**（适合 GitHub Pages，无需 COOP/COEP）
- 字体：嵌入霞鹜文楷子集（`LXGWWenKai-subset.ttf`，约 440KB 源 / ~310KB fontdata），项目默认 Theme，避免 Web 缺 CJK 字形
- 路径：合入 `main` 后由 Pages workflow 将 `public/` 拷入站点，访问 `/mojuan-sanguo/godot/`
- 源工程：本机 Godot playground（不在本仓）

试玩：打开 [index.html](./index.html)（需等 Deploy Pages 完成）。
